# Attribution and provenance

CHOG Clash adapts source code from **AETHER CLASH by Bang Tutorial**, [bangtutorial/aether-clash](https://github.com/bangtutorial/aether-clash), commit `1ac9751f86569b6b8c177994d5074a0d85faf94d`. The original code copyright and MIT license are retained in [LICENSE](LICENSE). Combat code, CPU behavior, combat kit timing remains derived from that source. Sprite coordinates, posing, collision presentation and several combat rules were upgraded locally on 12 October 2026. Original kit IDs are implementation details, with CHOG IDs exposed by the adapter.

The current working tree and runtime contain **no original Aether image, SVG, font, audio or video files**. Original stage artwork, combat effect textures, drone image, music, voice clips, dormant menu video, showcase portraits, screenshots and bundled fonts were removed. Original history is available in the linked upstream repository; this reviewer repository records a snapshot of the current CHOG Clash source. Original Aether media is not shipped. `tools/audit_media.py` compares file hashes across paths; results are in `validation/media-audit.json`.

Twelve character reference PNGs come from [CHOG Team](https://www.chog.xyz/team), stored unchanged in `assets/chog/reference/`. Their URLs and SHA-256 hashes are recorded in `assets/chog/source-provenance.json`. Their owners retain their rights; the Aether MIT license does not license CHOG character artwork. This is a local fan adaptation and does not claim official CHOG affiliation.

Five new arena illustrations were generated with the built-in OpenAI image_gen tool using the prompt set in `tools/arena-generation.json`. The final source PNGs are stored in `assets/chog/source-art/`; optimized runtime exports live in `assets/chog/arenas/`. The locations are game adaptations informed by the [official Chog Lore film](https://www.youtube.com/watch?v=P8NSHkL7Fxs), not copied film frames.

Character rigs, bodies, props, animation poses, portraits, icons and effects are authored in `tools/chog-art.js` and `tools/chog-effects.js`, with official CHOG reference images used for face textures and selection/cut-in illustrations. Music and ambience are composed in `tools/build_music.py`, without borrowed samples. Spoken announcer cues and twelve synthetic persona ultimate barks are generated locally by `tools/build_voice.py` with [Kokoro-82M](https://huggingface.co/hexgrad/Kokoro-82M) (Apache-2.0) and [kokoro-onnx](https://github.com/thewh1teagle/kokoro-onnx) (MIT). These are fan-game voices, not official CHOG actor performances. Build model weights remain outside the shipped game. The game interface uses device fonts; the comic landing bundles Bangers Regular and Barlow Regular/Bold from Google Fonts under their OFL licenses. Those fonts and license notices are in `assets/chog/landing/fonts/`; no Aether font is bundled. Higgsfield and separately billed API generation were not used.

Names of moves, combat styles, arena titles and the House Cup fighting premise are design choices for this adaptation. Verified public persona roles and the distinction between source lore and game proposals are documented in [LORE_RESEARCH.md](docs/LORE_RESEARCH.md).

Four additional landing illustrations were generated with built-in image_gen: city background, a transparent Yot/Rogue/Cookie ensemble, an origin-inspired panel and a Rogue/Tabsu showdown. Prompts and outputs are recorded in [tools/comic-generation.json](tools/comic-generation.json); source PNGs remain in `assets/chog/source-art/`. [COMIC_DESIGN.md](COMIC_DESIGN.md) records the research and original layout decisions. Marvel references informed comic design research; no Marvel characters, logos or panels are included.

Online implementation (13 October 2026) adds pinned Colyseus core/ws-transport 0.18 and browser SDK 0.18.5 (MIT), viem 2.57.4 (MIT), Express 5.3.0 (MIT) and OpenZeppelin Contracts 5.4.0 (MIT). The SDK license is shipped at `online/vendor/colyseus-LICENSE.txt`; backend/contract dependency licenses remain in their installed packages. Headless combat ports remain derived from the attributed Aether source. Media audit excludes installed dependencies, contract output/cache and private backend data.
